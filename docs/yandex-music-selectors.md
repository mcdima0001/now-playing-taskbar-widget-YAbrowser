# Разметка плеера Яндекс Музыки

Разобрано по двум снимкам страницы (`Сохранить как`) от 2026-09-04: обычный
плеер и «Моя волна». Сами снимки в репозиторий не легли — в них есть почта
владельца аккаунта и ссылка на его аватар, а репозиторий публичный. Лежат
рядом, вне гита: `.claude-local/yandex-music/{regular,vibe}-player.html`.

Хвост-хеш в классах (`__fQsOo`) меняется от релиза к релизу — цепляться
только за устойчивую часть через `[class*=]`.

## Кнопки транспорта

Подписи (`aria-label`) переживают смену раскладки лучше классов, но искать их
надо строго внутри плеербара: у треков в списках подписи те же.

| Действие | `aria-label` | Где |
|---|---|---|
| Предыдущая | `Предыдущая песня` | обе |
| Пауза/играть | `Пауза` / `Воспроизведение` | обе |
| Следующая | `Следующая песня` | обе |
| Перемешать | `В случайном порядке` | только обычный |
| Повтор | `Повтор` | только обычный |
| Заглушить | `Выключить звук` | обе |

## Перемешать и повтор: состояние читается по классу значка

Само состояние — в классе `svg` внутри кнопки. `aria-pressed` у обеих кнопок
тоже есть, но в снимках оба состояния выключенные (`false`), включённого
образца нет, а у класса значка полный набор известен из CSS — читать надёжнее
его. Заодно он различает три положения повтора, чего булев `aria-pressed`
не умеет.

```
ShuffleButton_shuffleIcon_off       перемешивание выключено
ShuffleButton_shuffleIcon_on        включено
ShuffleButton_shuffleIcon_disabled  недоступно (кнопка ещё и disabled/data-disabled)

RepeatButton_repeatIcon_none        повтор выключен
RepeatButton_repeatIcon_context     повторять список
RepeatButton_repeatIcon_one         повторять трек
RepeatButton_repeatIcon_disabled    недоступно
```

Полный список состояний взят из CSS-бандла страницы, не только из снимка DOM.
Ложится один в один на `ShuffleMode` (Off/On) и `RepeatMode`
(Off/Context/Track) в виджете; `Smart` у Яндекса аналога не имеет.

Перемешивание бывает недоступно (в снимке кнопка пришла с `disabled=""` и
`data-disabled="true"`) — виджету это состояние надо показывать серым, а не
делать вид, что выключено.

## Громкость

```html
<div class="ChangeVolume_root__…">
  <input class="… ChangeVolume_slider__…" type="range"
         max="1" step="0.01" value="1" aria-label="Управление громкостью">
  <button class="… ChangeVolume_button__…" aria-label="Выключить звук">
```

Диапазон 0…1 с шагом 0.01, не 0…100. Ставить значение — как полосе прогресса:
нативным сеттером `HTMLInputElement.prototype.value` плюс события `input` и
`change` вручную, иначе React со своим `valueTracker` правку не заметит
(`setRangeValue` в `content.js` уже так делает).

**Грабля:** этот слайдер лежит в том же DOM, что и полоса прогресса, и обе
находятся селектором `input[type=range]`. Отличаются только по `max`: у
громкости он `1`, у прогресса — длительность трека в секундах. Отсечка
`max <= 5` в `sliderProgress()` держится именно на этом — убрать её нельзя,
иначе виджет начнёт считать громкость позицией трека.
